# Netflix PostgreSQL Data Analysis

A SQL data analysis project using PostgreSQL and the Netflix Movies and TV Shows dataset.

This project was created to practice SQL and PostgreSQL concepts by analyzing real-world Netflix content data.

## Dataset

The dataset is taken from Kaggle:

Netflix Movies and TV Shows Dataset : https://www.kaggle.com/datasets/shivamb/netflix-shows

The dataset contains information about Netflix movies and TV shows, including:

- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genres
- Description

## Analysis Performed

Some of the analysis questions explored in this project:

- Find content added in the last 5 years
- Find the most common rating for Movies and TV Shows
- Find TV Shows with more than 5 seasons
- Count Netflix content by genre
- Find Pakistani movies
- Find cast members from Pakistani movies
- Find the top 10 cast members in Pakistani movies
- Categorize content based on words in descriptions
- Count content by category
